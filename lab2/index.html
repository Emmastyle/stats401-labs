Visual Encoding Guide

Population: x-position and lollipop line length (farther right means larger population).

Temperature (temp_c): endpoint shape using tertile bins from the data (lower third = circle, middle third = square, upper third = triangle).

Development Level: line style (Low = dashed line, Medium = thin solid line, High = thick solid line).

Region: color categories with explicit legend labels (North, South, East, West).

Design Justification

I used a grouped lollipop-style chart to keep the display readable while encoding all four required variables. Population (ratio) is mapped to horizontal position and stem length, so differences in city size can be compared quickly on one axis. Region (nominal) is mapped to color, which naturally supports category grouping and makes regional patterns easy to scan. Temperature in Celsius (interval) is mapped to endpoint shape using tertile bins (lower third, middle third, upper third), which keeps category counts balanced and avoids arbitrary fixed cut points. Development level (ordinal) is mapped to line style in an ordered way: Low is dashed, Medium is a thin solid line, and High is a thick solid line. City names appear on the y-axis and exact values are available in tooltips, allowing both overview and detailed inspection.

How the command becomes a map change

Click Start Voice Control. The browser asks for the microphone only after that click.

Heard is the transcript. Action is what the map did. If the phrase is not recognized, the action line lists commands that work.

Show Europe calls filterRegion: countries outside Europe dim on both maps, and the choropleth zooms to Europe. Highlight Japan calls highlightCountry and pins that country in both views. Reset calls resetVisualization.

Fallback. The same functions are wired to the buttons, the country menu, click, hover, and the keyboard. Press A, E, N, S, F, or O for a region, R or Escape to reset, and + or − to zoom. The maps stay usable when speech recognition is missing or permission is denied.

Privacy. Listening stays on through a short pause, so the rest of the command is not cut off. Press Stop Voice Control to end it sooner. This page does not store the recording. In Chromium, the Web Speech API sends audio to the browser’s speech service, so leave the button unpressed if you do not want that.

Design reflection

What was extended, what the voice commands do, and where recognition fails.

I extended the Lab 9 coordinated choropleth and contiguous cartogram of 2025 nominal GDP. The novel modality is voice, using the browser Web Speech API. The microphone opens only after Start Voice Control is clicked, and one transcript is passed to handleVoiceCommand. That function calls the same actions as the pointer: filterRegion, highlightCountry, and resetVisualization. Saying “Show Europe” dims every country outside Europe and zooms the choropleth to the region. “Highlight Japan” pins Japan on both maps. “Reset” clears the filter, the pin, and the zoom. Voice fits this task because a region or a country is easier to name than to point at. Compact high-GDP economies such as Singapore, Belgium, and the Netherlands are easy to miss with a cursor and easy to say. Region buttons, the country menu, click, hover, and keyboard shortcuts remain available when recognition fails or microphone permission is denied. Short names are often misheard, and Chromium sends the audio to the browser speech service rather than recognizing it on the page. The status line always shows the heard text and the action taken, so a wrong command can be corrected at once.

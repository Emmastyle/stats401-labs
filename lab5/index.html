A synthetic urban transit system with five districts and 50 direct connections

Each node is a station. district is its administrative area, daily_passengers is approximate daily volume, and station_type is Local, Transfer, or Terminal. Each link is a direct ride: travel_time_min is the time between the pair, and route_type is Metro, Express, or Shuttle. A link means passengers can travel between those two stations without changing to another connection first. The network is treated as undirected.

2. Node-Link Visualization

Drag stations to untangle the layout. Hover to isolate neighbors.

Loading data

Visual Encoding Guide

district: node color, plus a weak geographic force that keeps each district loosely clustered.

daily_passengers: node size on a square-root scale.

station_type: node shape (circle = Local, diamond = Transfer, square = Terminal).

travel_time_min: link width. Longer direct rides are thicker so slow connections stay visible.

route_type: link color; Shuttle routes are dashed.

3. Node-Link Design Description

District is mapped to node color, and a weak geographic force keeps each district loosely clustered, so the view behaves a bit like a city map. Daily passenger volume uses a square-root size scale: busy stations read as heavier without letting the largest hubs erase smaller stops. Station type uses shape—circle for Local, diamond for Transfer, square for Terminal—so role does not compete with district color. Travel time is mapped to link width so the slowest direct rides become the most salient; route type uses link color, with dashed strokes for Shuttles. Dragging untangles crossings, hover highlighting isolates a station’s neighbors, and tooltips name every station and its attributes.

4. Adjacency Matrix

Rows and columns are stations, ordered by district and then by station type.

50 × 50 matrix

Matrix encodings

Row / column: one station. Order is district, then Transfer → Local → Terminal.

Filled cell: a direct connection. Empty cells stay light gray.

Cell color: route type. Opacity: travel time (darker = longer).

Label color: district. Label mark: station type (Tf = Transfer, L = Local, Te = Terminal).

5. Matrix Design Description

The matrix uses the same stations as rows and columns, ordered by district and then by station type. Intra-district routes form block-diagonal clusters; inter-district bridges appear as off-block cells. A filled cell is a direct connection, cell color encodes route type, and opacity encodes travel time (darker means longer). Labels use district color, with a small shape mark for station type. Passenger volume is omitted here so the grid stays readable; volume is left to the node-link view.

6. Network Questions and Findings

Each answer comes from the visualizations above, not from reading the CSV alone.

Question Answerable? Best view Encoding / interaction Observation from the visualization
1. Which stations appear central in the network? Well Node-link; matrix supports it How many links meet a node; hover highlighting; diamond transfer marks at cluster centers Station 5, the Central Transfer, is the clearest hub: many links leave it toward every district, and hovering it lights up neighbors on all sides. Station 25 is the next most connected hub. In the matrix, Station 5’s row also shows more filled cells than a typical local stop.
2. Which districts are strongly connected to one another? Well Both, especially the ordered matrix District-block ordering; off-block cells; inter-district link colors in the node-link view Central is the bridge district. The matrix shows filled cells from the Central block into North, South, East, and West. North and South also share a direct Express cell. East and West have no direct off-block cell between them; they meet through Central.
3. Where are transfer or terminal stations located in the topology? Well Node-link Shape (diamond vs square) plus position after the force layout settles Transfer diamonds sit at the center of each district cluster (Stations 5, 8, 15, 18, 25, 35, and 45). Terminal squares sit at the outer ends of dashed Shuttle links and keep a single connection. The matrix marks type beside each label, but the leaf-versus-hub geometry is much clearer in the node-link view.
4. Which stations have high passenger volume? Well in the node-link view; not easily in the matrix Node-link Node size Station 5 is the largest node. Stations 15, 25, and 2 are also among the highest-volume stations — Station 2 stands out because it is a large Local circle, not a Transfer diamond. I did not encode volume in the matrix, so this question is difficult there on purpose.
5. Where are the longest direct travel-time connections? Well Both Link width in the node-link view; cell opacity in the matrix The thickest lines and darkest cells are Station 30–29 (a long peripheral Shuttle), Station 15–25 (a North–South Express), Station 20–19 (another outer Shuttle), and Station 5–45 (a Central–West Express). Long Shuttles sit at the edge of a district; long Express links cross districts.
6. Are particular route types concentrated in particular parts of the network? Well Both Link / cell color; dashed Shuttle strokes; district blocks Metro dominates the interior of each district block as short spokes into the local hub. Express appears only on a few inter-district bridges (Central–North, Central–West, and North–South). Shuttle is concentrated on the outer Terminal connections, visible as dashed edges at the periphery and as muted cells near the edges of each district block.

Each node is a station. district is its administrative area, daily_passengers is approximate daily volume, and station_type is Local, Transfer, or Terminal. Each link is a direct ride: travel_time_min is the time between the pair, and route_type is Metro, Express, or Shuttle. A link means passengers can travel between those two stations without changing to another connection first. The network is treated as undirected. Five stations have no routes at all, so they appear in the node table but not as endpoints in the route table.

Visual Encoding Guide

district: node color, plus a weak geographic force that keeps each district loosely clustered.

daily_passengers: node size on a square-root scale.

station_type: node shape (circle = Local, diamond = Transfer, square = Terminal).

travel_time_min: link width. Longer direct rides are thicker so slow connections stay visible.

route_type: link color from d3.schemeSet2; Shuttle routes are also dashed.

3. Node-Link Design Description

District is mapped to node color, and a weak geographic force keeps each district loosely clustered, so color and position both carry membership. Daily passenger volume uses a square-root size scale, which is why Stations 48 to 50 look heavy. Station type uses shape: circle for Local, diamond for Transfer, and square for Terminal, because role should not reuse the district color. Size and shape are kept apart on purpose: some of the largest stations have no routes. Travel time is mapped to link width so slower direct rides stand out as thicker lines; route type uses a second color scale, with dashed strokes for Shuttles. Dragging, neighbor highlighting, and tooltips are there to inspect one station at a time in a dense layout.

4. Adjacency Matrix

Rows and columns are stations in ID order, so the consecutive backbone sits near the diagonal.

50 × 50 matrix

Matrix encodings

Row / column: one station, ordered by station ID so consecutive routes form a near-diagonal band.

Filled cell: a direct connection. Empty cells stay light gray.

Cell color: route type. Opacity: travel time (darker = longer).

Label color: district. Label mark: station type (Tf = Transfer, L = Local, Te = Terminal).

5. Matrix Design Description

The matrix uses the same stations as rows and columns, ordered by station ID. Filled cells mark a direct connection. I kept extra encodings light: cell color is route type and opacity is travel time, so the darkest cell is the slowest ride. Labels use district color and a small type mark. I ordered by ID rather than by district so consecutive routes stay near the diagonal; skip connections then fall farther off the diagonal. Passenger volume is left out of the grid so it stays readable.

6. Network Questions and Findings

Each answer comes from the visualizations above, not from reading the CSV alone.

Question Answerable? Best view Encoding / interaction Observation from the visualization
1. Which stations appear central in the network? Partially Node-link How many links meet a node on hover; node size; district color of neighbors There is no star hub. Hover highlighting shows that the best-connected stations have only three neighbors. Station 38 is the one that looks most central in this view: it is the largest Transfer that also has three links, including short rides to other large stations (37 and 39). Stations 48 and 49 are even larger, but they have no links, so size alone does not mean centrality.
2. Which districts are strongly connected to one another? Partially Node-link; the matrix only weakly District color and the geographic clustering force; cross-color links Every district color appears in the connected component and has links into other colors, so no district is an island. I did not order the matrix by district, so ranking a single strongest pair is not easy from that view. In the node-link, extra skip links also run between the East and South clusters, but five colors still look interwoven rather than two districts dominating.
3. Where are transfer or terminal stations located in the topology? Well for transfers; only partly for terminals Node-link Shape: diamonds for Transfer, squares for Terminal Every Transfer diamond sits in the connected part of the graph. Terminals split: many squares lie on the same connected chain, but Stations 43, 46, and 49 are Terminal squares with no links and sit outside that component.
4. Which stations have high passenger volume? Well in the node-link view; not easily in the matrix Node-link Node size Stations 48, 49, and 50 are the three largest nodes. High volume is not the same as being on a route: 48 and 49 have no links, and 50 has only one. Passenger volume is not encoded in the matrix.
5. Where are the longest direct travel-time connections? Well Both Cell opacity in the matrix (darker = longer); link width in the node-link view (thicker = longer) The longest direct ride is Station 7–31: it is the darkest filled cell and the thickest Express link. The next-darkest skip cells are Station 18–34 and Station 29–50. Those three stand out more than the consecutive backbone links.
6. Are particular route types concentrated in particular parts of the network? Not easily in the node-link view; partly in the matrix Both Link / cell color; dashed Shuttle strokes; ID-ordered diagonal band In the node-link view, Metro, Express, and Shuttle colors are mixed through the connected graph, not pooled in one district. The ID-ordered matrix also does not show a block of one route type. Types alternate along the near-diagonal band instead of concentrating in one region.

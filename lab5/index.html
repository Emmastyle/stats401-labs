1. Dataset Description

A synthetic urban transit system with five districts and 50 direct connections

50 stations · 50 routes

Districts
Central, North, South, East, West
Network
Undirected transit connections

Each node is a station. district is its administrative area, daily_passengers is approximate daily volume, and station_type is Local, Transfer, or Terminal. Each link is a direct ride: travel_time_min is the time between the pair, and route_type is Metro, Express, or Shuttle. A link means passengers can travel between those two stations without changing to another connection first. The network is treated as undirected.

2. Node-Link Visualization

Drag stations to untangle the layout. Hover to isolate neighbors.

Visual Encoding Guide

district: node color, plus a weak geographic force that keeps each district loosely clustered.

daily_passengers: node size on a square-root scale.

station_type: node shape (circle = Local, diamond = Transfer, square = Terminal).

travel_time_min: link width. Longer direct rides are thicker so slow connections stay visible.

route_type: link color from d3.schemeSet2; Shuttle routes are also dashed.

3. Node-Link Design Description

District is mapped to node color, and a weak geographic force keeps each district loosely clustered, so the view behaves a bit like a city map. Daily passenger volume uses a square-root size scale. Station type uses shape—circle for Local, diamond for Transfer, square for Terminal—so role does not compete with district color. Keeping size and shape separate matters here: some of the largest stations have no routes at all. Travel time is mapped to link width so the slowest direct rides stand out; route type uses link color, with dashed strokes for Shuttles. Dragging untangles the chain, hover highlighting isolates a station’s neighbors, and tooltips name every station and its attributes.

4. Adjacency Matrix

Rows and columns are stations in ID order, so the consecutive backbone sits near the diagonal.

50 × 50 matrix

Matrix encodings

Row / column: one station, ordered by station ID so consecutive routes form a near-diagonal band.

Filled cell: a direct connection. Empty cells stay light gray.

Cell color: route type. Opacity: travel time (darker = longer).

Label color: district. Label mark: station type (Tf = Transfer, L = Local, Te = Terminal).

5. Matrix Design Description

The matrix uses the same stations as rows and columns, ordered by station ID. Most routes join consecutive IDs, so the backbone appears as a band next to the diagonal, and the ten skip connections appear as darker cells farther away. Label color still encodes district, which makes the repeating Central–North–South–East–West cycle readable along the axes. Cell color encodes route type and opacity encodes travel time. I did not group by district, because that would scatter the path and hide the chain that actually structures this network.

6. Network Questions and Findings

Each answer comes from the visualizations above, not from reading the CSV alone.

Question Answerable? Best view Encoding / interaction Observation from the visualization
1. Which stations appear central in the network? Partially Both How many links meet a node; hover highlighting; filled cells in a station’s matrix row This is a backbone from Station 1 to Station 41, not a star hub. Most stations have two neighbors. About fourteen stations look slightly more central because they also sit on a skip link and have three neighbors—for example Stations 4, 7, 16, 21, and 31. Hovering them lights up only those few ties. Stations 42, 43, 46, 48, and 49 have no links, so they sit apart in the node-link view and have empty matrix rows.
2. Which districts are strongly connected to one another? Well Both, especially the ID-ordered matrix plus district-colored labels District color on nodes and matrix labels; the near-diagonal band of consecutive routes The backbone steps through districts in a repeating cycle: Central–North–South–East–West. Neighboring districts in that cycle are the strongly connected pairs, visible as consecutive label colors along the diagonal. Intra-district ties are rare: only two Central Shuttles (Stations 1–16 and 21–41) appear as off-diagonal cells. East–South also shows extra skip links.
3. Where are transfer or terminal stations located in the topology? Well Node-link; matrix labels support it Shape (diamond vs square vs circle) plus the Tf / Te / L marks on matrix axes Transfer, Terminal, and Local stations are interleaved along the chain (square, diamond, circle, repeat), not clustered at a hub or at the edge. Several terminals even sit on skip links (Stations 4, 7, 16, 25, 31). Isolated terminals—Stations 43, 46, and 49—are the exception: they are large squares with no connections.
4. Which stations have high passenger volume? Well in the node-link view; not easily in the matrix Node-link Node size Size grows with station ID. Station 50 is the largest node, followed by 49, 48, and 47. High volume is not the same as being connected: Stations 49, 48, 46, and 43 are among the biggest nodes but have no routes. I did not encode volume in the matrix, so this question is difficult there on purpose.
5. Where are the longest direct travel-time connections? Well Both Link width in the node-link view; cell opacity and off-diagonal position in the matrix The thickest lines and darkest off-diagonal cells are skip Express routes: Station 7–31 (16 min), Station 18–34 (15 min), and Station 29–50 (14 min). Several 12-minute rides also stand out, including sequential links such as Station 7–8 and skip links such as Station 4–23. The longest rides jump farther along the ID axis, not just along the backbone.
6. Are particular route types concentrated in particular parts of the network? Well Both Link / cell color; dashed Shuttle strokes; repeating pattern along the diagonal Route types are not concentrated in one district. Along the backbone they cycle Express, Shuttle, Metro, which appears as a repeating color and dash pattern on consecutive links and as a striped near-diagonal in the matrix. The skip connections mix all three types as well; the longest skips tend to be Express.

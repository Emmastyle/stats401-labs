Visual Encoding Guide

Date: horizontal position from late December 2023 through mid-March 2024.

Sentiment score: vertical position, from more negative (−1) to more positive (+1). The dashed line is a neutral score of 0.

Sentiment class: point color (Negative, Neutral, Positive), taken from the class with the highest RoBERTa probability.

Likes: point size. Larger circles received more likes.

Launch: the vertical marker is 2 February 2024, the U.S. Apple Vision Pro launch date.

Short Analysis

This assignment uses 1,211 public Apple Vision Pro tweets from a Hugging Face dataset (MIT license), covering late December 2023 to mid-March 2024. The raw file had duplicate tweet IDs with shifted timestamps, @-prefixed usernames, extra whitespace, and view counts stored as strings. Cleaning dropped empty text, kept the first copy of each ID, parsed timestamps to UTC, converted likes, retweets, and views to numbers, and standardized usernames. Sentiment is a RoBERTa estimate rather than a ground-truth label: twitter-roberta-base-sentiment-latest scores lightly normalized tweet text, and the plotted value is P(positive) minus P(negative). The chart maps date to x, that score to y, predicted class to color, and likes to size, with a line at the 2 February 2024 U.S. launch. Positive posts outnumber negative ones. Tweets with 20 or more likes are more often positive than low-engagement posts, and Friday has the lowest average score.

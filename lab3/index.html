Method
HTML scraping with Python requests + BeautifulSoup
Records collected
1,000

Each row represents one book listing and includes its original title, category, price in British pounds, and star rating. The Python script discovers all 50 categories, follows every category page automatically, waits one second between requests, handles request errors, and saves the resulting dataset as CSV. Punctuation such as hashtags, quotation marks, and parentheses is preserved because it is part of the source title.
